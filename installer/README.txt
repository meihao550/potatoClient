PotatoClient - Minecraft Bedrock クライアント
==============================================

■ 注意（必ずお読みください）
- シングルプレイ / 自分のワールド専用です。公開サーバーや Realms で使うと
  規約違反となり、BAN の対象になります。
- 対応しているのは Minecraft Bedrock 1.26.52（GDK 版 / Microsoft Store・Xbox アプリ版）だけです。
  ゲームが更新されると動かなくなります。
- ゲームのプロセスに DLL を読み込ませる仕組みのため、ウイルス対策ソフトや
  SmartScreen が警告を出すことがあります。公式の配布元
  (https://github.com/meihao550/potatoClient) から入手したものか確認してください。

■ 使い方
1. Minecraft を起動し、シングルプレイのワールドに入る
2. スタートメニューの「PotatoClient Injector」を実行する
3. 「Inject 成功!」と表示されたら Enter で閉じる

■ 操作
  Insert : メニュー表示 / 非表示
  Home   : コマンド欄（help でコマンド一覧）
  End    : アンロード（もう一度 Injector を実行すれば再度使えます）

■ うまくいかないとき
- 「起動していません」 → Minecraft を先に起動してください
- 「LoadLibraryW が失敗しました」 → ゲームのバージョンが 1.26.52 か確認してください
- アンインストールは「設定 > アプリ」または スタートメニューの「PotatoClient をアンインストール」から


PotatoClient - Minecraft Bedrock client (English)
-------------------------------------------------
- Single-player / your own worlds only. Using it on public servers or Realms
  breaks their rules and can get you banned.
- Supports Minecraft Bedrock 1.26.52 (GDK) only.
- Antivirus / SmartScreen may warn because it injects a DLL into the game.
  Only use builds from https://github.com/meihao550/potatoClient

Usage: start Minecraft, enter a single-player world, then run
"PotatoClient Injector" from the Start menu.
Keys: Insert = menu, Home = command bar, End = unload.
